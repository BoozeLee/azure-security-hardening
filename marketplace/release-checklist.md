# Monetized Release Checklist

## Product

- [ ] Offer and target customer are clear
- [ ] Pricing approved
- [ ] License/support terms approved
- [ ] Screenshots or demo assets ready
- [ ] README includes monetization section

## GitHub

- [ ] `gh auth status` is valid
- [ ] Branch created, not direct push to main
- [ ] `.github/FUNDING.yml` added where appropriate
- [ ] PR opened

## Stripe

- [ ] Product payload drafted
- [ ] Price payload drafted
- [ ] No raw secrets in repo
- [ ] Product/price creation explicitly approved
- [ ] Created product/price IDs stored as non-secret metadata

## Legal/Trust

- [ ] PRIVACY.md
- [ ] SUPPORT.md
- [ ] SECURITY.md
- [ ] TERMS/EULA if selling software directly
