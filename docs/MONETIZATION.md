# Monetization Plan

## Offer

Azure Security Hardening is monetized through:

- GitHub Sponsors
- Direct Stripe checkout
- Paid support
- Marketplace listing if applicable

## Free Tier

Open source usage and evaluation builds.

## Paid Tier

Commercial support, implementation help, and premium delivery artifacts.

## Support

Use GitHub Issues for public support and commercial inquiry routing.

## Stripe

Stripe credentials are not stored in this repo. Agents use `beehive-stripe` and
Postman secret environment variables.

## GitHub Sponsors

The repository may use `.github/FUNDING.yml` to display sponsor links.

## Marketplace

Only GitHub Actions and real GitHub Apps should claim GitHub Marketplace
readiness.
